Sign in with your Minecraft account

  1. Launch the game and open Multiplayer.
  2. Pick the Wispcraft Settings entry (or the Wisp Settings button in the relay list).
  3. Choose Add an account. The game shows a short code and a link.
  4. Open microsoft.com/link on any device and enter that code, then approve the sign-in.
  5. The account appears in the dropdown — select it. Your real username and skin are used from then on.

You don't have to do this by hand: opening the game asks you to sign in right away and shows the code itself, then reloads once so your account and skin are active. Close the panel with the × if you only want singleplayer.

No signed-in account found in this browser.

Signing in stores a Microsoft refresh token and a Minecraft session token in this browser's localStorage, so the game stays signed in. Anyone using this browser profile can play as you until you clear it — use the button above on shared or school machines.

Join a real server

  1. Multiplayer → Direct Connection.
  2. For a normal Java server, start the address with java:// — e.g. java://mc.hypixel.net or java://play.example.com:25566.
  3. For an Eaglercraft server, start the address with wss:// instead.

Premium servers only accept you once you are signed in. Minecraft 26.3 client ⇒ Java 1.8–1.21 servers may still refuse older/newer protocol versions.

Wisp relay

Save with the field empty to return to the default relay. Relays are probed from this browser, so a row that fails here fails for the game too. Play checks your relay first and switches only when it does not answer; once in game, change it live under Wisp Settings → Wisp Server.

Read this first

  • All server traffic is tunneled through the Wisp relay you pick. Whoever runs it can technically see your connection metadata.
  • Hypixel and some other networks dislike VPN/proxy traffic; using this with your real account is at your own risk and could get the account flagged.
  • Your Microsoft login happens directly between your browser and Microsoft. The sign-in code is never sent to this site, and tokens live only in this browser's localStorage.
